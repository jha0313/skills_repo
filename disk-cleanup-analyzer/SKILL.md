# 디스크 정리 분석

**먼저 알 것**: macOS 전용이다. 스크립트 두 개는 읽기만 하고, 지우는 명령은 승인 뒤에 네가 직접 친다. 보고서의 크기는 실제로 늘어날 여유 공간과 다를 수 있다(APFS 복제·스냅샷, 겹치는 폴더). 세션 판정은 Claude Code의 작업 폴더만 본다. 다른 에이전트의 폴더는 판정하지 못하므로 후보에 넣지 않는다.

아래 `S`는 이 스킬 폴더의 `scripts`다.

## 언제 쓰나

- 용량이 부족하다, 무엇이 큰지 알고 싶다, 정리하자는 요청. 몇 달 뒤 다시 돌려도 된다(매번 새로 잰다).
- 쓰지 않는 때: 한 프로젝트 안의 청소(`git clean` 등), 외장 볼륨, 속도·메모리 문제, 지울 파일을 사용자가 이미 정확히 지정한 때.

## 순서

1. **재기.** `python3 -I S/scan.py`를 백그라운드로 돌린다. 홈과 `/Library`만 걷고 몇 분 걸린다. 앱이 의심되면 `/Applications`를 인자로 더 준다. macOS 권한 창이 뜰 수 있다고 미리 알린다. 거부해도 계속 돌고, 못 읽은 곳은 끝에 적힌다.
   완료: 여유 용량, 큰 폴더 표, 큰 파일 표가 있다.
2. **세션 판정.** `python3 -I S/session_dirs.py`를 돌린다.
   완료: KEEP / REVIEW / ASK 표가 있다. "확인 실패"가 있으면 전부 KEEP이다. 그대로 보고하고 다음으로 간다.
3. **분류.** [references/classify.md](references/classify.md)를 읽고 표의 항목을 ① 다시 만들어지는 캐시 ② 검토 ③ 사용자 콘텐츠로 나눈다. ①에 넣으려면 문서에 적힌 확인을 이 컴퓨터에서 해 본다.
   완료: 1 GB 이상인 모든 항목이 ①②③ 중 하나에 있다. 확인하지 못한 것은 ②다.
4. **보고.** 아래 답 형식으로 낸다.
   **보고서를 보여 주지 않았으면 5로 가지 않는다.**
5. **항목별로 묻기.** 항목 하나에 선택 하나. 항목마다 전체 경로, 크기, 마지막 수정 시각, 무엇이 어떻게 다시 만들어지나(모르면 "모름")를 적는다. 세션 폴더에는 세션 제목, 마지막 활동, 판정, 파일 예시를 더한다.
   - 정리 명령을 쓸 항목이면 먼저 dry-run을 돌려 지울 목록을 보여 준다. 캐시 밖 대상이 있으면 그것을 따로 묻는다.
   - 묻기 직전에 항목마다 기록한다: `python3 -I S/scan.py --record <경로> > <기록.json>`. 기록은 지울 폴더 밖에 항목마다 하나 둔다. 크기와 시각은 기록의 `shown`을 보여 준다.
   - ASK: 폴더마다 따로 묻는다. REVIEW: "영구 폴더로 옮기기"와 "그대로 두기"만 묻는다. KEEP: 묻지 않는다.
   **사용자가 그 항목을 골랐다는 답이 없으면 6으로 가지 않는다.** "알아서 정리해"는 승인이 아니다.
6. **지우기 직전 확인, 그다음 지우기.** 승인된 항목마다 차례로 한다.
   - `python3 -I S/scan.py --check <기록.json>`을 돌린다. **종료 코드가 0이 아니면 지우지 않는다.** 1(달라짐)이면 새로 기록하고 다시 묻는다. 2(확인 못 함)면 뺀다.
   - `lsof +D <폴더>` 또는 `lsof <파일>`에 무엇이 나오면 어느 앱인지 알리고 멈춘다.
   - 세션 폴더면 `session_dirs.py`를 다시 돌린다. ASK가 아니게 됐으면 뺀다.
   - 정리 명령이 있으면 dry-run을 다시 돌려 승인받은 목록과 같을 때만 친다. 없으면 `--check`가 낸 `같음:` 뒤의 경로를 그대로 넣은 명령을 친다. 표의 경로를 다시 적지 않는다.
   완료: 승인된 항목마다 "지움 / 뺌 + 이유"가 있다.
7. **다시 재기.** `python3 -I S/scan.py --free`. 완료: 전과 후의 여유 용량이 있다. 거의 안 늘었으면 그대로 말한다(스냅샷, 하드 링크, 열린 파일).

## 세션 폴더 판정

열어 둔 채 며칠 쉬는 세션은 `lsof`에도 프로세스 인자에도 잘 나타나지 않는다. 그 폴더에 하나뿐인 원본(사이트 소스, 아직 실행하지 않은 패치)이 있을 수 있다. 그래서 "끝난 세션 같다"는 짐작 대신 스크립트 판정만 쓴다.

| 판정 | 뜻 | 할 수 있는 일 |
|---|---|---|
| KEEP | 열려 있음, 최근 7일 안에 바뀜, 대화 기록을 못 찾음, 확인 실패 중 하나 | 없음 |
| REVIEW | 오래 쉬었지만 원본일 수 있는 파일이 있음(캐시 폴더 안 포함) | 파일 목록을 보여 주고 옮길지 묻기 |
| ASK | 오래 쉬었고 남은 것이 로그·임시 파일뿐 | 폴더별로 묻기 |

- 판정을 바꾸지 않는다. 표에 없는 폴더는 KEEP과 같게 다룬다. 기본 7일은 늘릴 수만 있다(`--days 14`).
- 다음은 이름에 tmp·cache가 있어도 후보가 아니다: `~/.claude/**`(대화 기록·작업), `.claude/worktrees/`, `~/.codex/**`. 대화 기록이 크면 도구의 보관 기간 설정(Claude Code는 `cleanupPeriodDays`)만 알려 준다.
- 스크립트는 세션 제목을 찾으려고 대화 기록을 읽고 제목만 출력한다. 보고서를 남과 나누기 전에 제목을 확인하게 한다.

## 근거

- 크기·날짜·판정은 스크립트 출력에서만 가져온다. 표를 다시 계산하거나 줄이지 않는다.
- "다시 만들어진다"에는 근거를 붙인다: 도구의 정리·경로 명령 출력, 공식 문서, 또는 "확인 못 함".
- 스킬을 고쳤으면 `python3 tests/run_tests.py` 통과 결과를 보인다.

## 하지 말 것

- `sudo`, 강제 종료, 휴지통 비우기. 권한이 필요한 것은 표에 적고 사용자가 한다.
- 여러 항목을 묶은 선택지("끝난 세션 2개 삭제"), 경로에 glob이나 변수를 쓴 삭제 명령. 승인한 것보다 넓게 지워진다.
- 사진·문서·영상·다운로드를 정리 후보로 제안하기. 옮기기만 안내한다.
- 루트 전체 검색. 느리고 권한 창이 이어서 뜬다.
- 삭제 자동화. 예약 실행을 원하면 1~4만, 보고서까지다.

## 답 형식

1. 디스크: 전체 / 사용 / 여유, 잰 시각, 못 읽은 곳 수
2. ① 다시 만들어지는 캐시: 경로, 크기, 마지막 수정, 무엇이 다시 만들어지나, 확인한 방법
3. ② 검토: 경로, 크기, 마지막 수정, 왜 모르나, 사용자가 확인할 방법
4. ③ 사용자 콘텐츠: 경로와 크기만
5. 세션 폴더: `session_dirs.py` 표 그대로
6. 물을 것: 항목별 선택지. 아직 아무것도 지우지 않았다는 한 줄
7. (지웠다면) 전 → 후 여유 용량, 지운 것, 뺀 것과 이유
