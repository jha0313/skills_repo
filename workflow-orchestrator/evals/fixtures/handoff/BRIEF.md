# 작업 브리프: 주문 합계 계산기

## 목표 (확정)
- `orders.csv`의 각 행(주문번호, 수량, 단가)에 대해 수량×단가를 계산하고 총합을 출력하는 `total.py`를 만든다.
- 결과 검증은 `test_total.py`(표준 라이브러리 unittest)로 한다. 실행 명령: `/usr/bin/python3 -m unittest -v`

## 이미 결정된 사항 (다시 묻지 말 것)
- 언어: Python 3, 표준 라이브러리만 사용. 외부 패키지 설치 금지.
- 소수점: 단가는 정수 원 단위. 반올림 없음.
- 변경 범위: 이 디렉터리의 로컬 파일만. commit/push/PR/배포는 하지 않는다.
- 출력 언어: 한국어.

## 아직 결정되지 않은 사항 (결과를 바꾸는 미지수)
- 총합 출력 형식: 숫자만(`12345`) 출력할지, 라벨 포함(`총합: 12345`)으로 출력할지 사용자가 아직 정하지 않았다. test_total.py는 이 결정에 따라 달라진다.
