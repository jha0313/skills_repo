## 발표 화면 조작

키보드 방향키로 장을 넘긴다. 고유 조작이 있는 장은 **INTERACTIVE**와 사용 방법을 표시한다. 전체 슬라이드·발표자 노트·테마·인쇄는 화면 메뉴에서 사용할 수 있다. 영상 재생이나 설명용 제어가 새 AI 작업·배포를 실행하지는 않는다.

## 공유 범위

내부 설문 수치와 원문은 제외했다. 예시·개인 경험·실제 관찰을 구분하며, 공개판의 세 번째 장은 오늘 다룰 문제와 주제를 소개한다. 원시 도구 로그, 하위 에이전트 대화, 로컬 계정·경로, 백업, 내부 DB 자료는 포함하지 않는다.

실제 평가의 8/10→9/10은 같은 조건의10개 사례 한 쌍에서 관찰한 변화다. 두 실행 모두 종합 FAIL이며 일반적인 성능 향상이나 스킬 사용 유무 A/B의 증거가 아니다. 원본 전체 보고서 대신 발표에 필요한 짧은 원문 근거만 담았다.

공개본은 완성된 HTML과 필요한 자산을 제공한다. 빌더는 미포함이며 슬라이드는 원본 저자가 로컬에서 빌드한 결과물이다. 로컬 제작 환경에 의존하는 브랜드 원본·전체 평가 실행 폴더도 포함하지 않는다. 발표 슬라이드는 Google Fonts와 PNG 내보내기용 스크립트를 외부에서 불러오므로 완전한 오프라인 동작을 보장하지 않는다. 오프라인이면 시스템 글꼴로 대체된다.
