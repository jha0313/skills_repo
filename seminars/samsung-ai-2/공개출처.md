## Slide 3 편집 원칙

- 원본 Slide 3은 사전에 공유받은 내부 설문의 집계를 보여줬다. 공개판은 응답 수·비율·원문·표를 모두 제외하고, **AI 도입 뒤 흔히 늘어나는 일** 세 가지 — 결과 검증·재작업, 새 기능·활용법 학습, 동시 업무 관리 — 를 정성적으로 소개한다.
- 설문을 바탕으로 구성했다는 사실만 한 문장으로 남긴다. 세 항목을 특정 조직의 실측 통계로 인용하지 않는다.
- 헤드라인 「생성 뒤에 늘어난 일」과 뒤이은 두 파트 소개는 원본과 같다.

## 데모 근거의 공개 출처

- **Slide 13 · AutoKliq**: [PR #80](https://github.com/careerhackeralex/autokliq/pull/80)(채널 프로듀서 작업실, 대표)과 [PR #81](https://github.com/careerhackeralex/autokliq/pull/81)(썸네일 UI/UX, 대안), 영상 2개, deck에 내장한 선별 발췌(근거 overlay). 원본 리플레이 페이지·ZIP·raw 도구 기록·하위 에이전트 대화는 포함하지 않는다.
- **Slide 24 · skill-evaluator**: Before 8/10 통과·평균 4.434/5·종합 FAIL, After 9/10 통과·평균 4.4605/5·종합 FAIL. TC-007은 채점상 FAIL→PASS이나 응답 말미의 재승인 확인 문장이 남았고, TC-010은 FAIL 유지. 같은 criteria·evaluator·모델 조건의 10개 사례 한 쌍을 관찰한 것이며 일반적인 성능 향상이나 스킬 사용 유무 A/B의 증거가 아니다. 원본 REPORT·run 디렉터리·criteria/evaluator hash 값은 포함하지 않는다.

## 포함하지 않은 것

- 내부 설문의 집계 파일·근거 메모, 세미나 요청·요구사항 메모, 진행 인수인계 기록, 검증 결과 같은 로컬 receipt.
- deck 빌더와 레이아웃 소스, 브랜드 참조 템플릿. **빌더 미포함, 슬라이드는 원본 저자의 로컬 빌드 결과물**이다. 발표자의 개인 슬라이드 키트와 로컬 절대경로에 의존해 이 저장소만으로는 재현할 수 없으므로 완성 HTML만 제공한다.
- 원본 평가 run(REPORT.html, 사례별 평가 파일, trace, tool 입출력), 데모 리플레이 원본과 ZIP, 원시 대화 로그.
- 이전 27장·DX 버전 아카이브, 백업, 원고 생성 기록.
- 계정·이메일·연락처, 주최 측 담당자 정보.

## 외부 리소스와 동작

- `slides/index.html`은 Google Fonts(Inter, Noto Sans KR) 스타일시트 2건과 preconnect 1건, 슬라이드 PNG 내보내기용 `html-to-image` 스크립트 1건(jsdelivr)을 외부에서 불러온다. 오프라인이면 시스템 글꼴로 대체되고 PNG 내보내기만 동작하지 않는다. 그 외 이미지는 data URI, 영상은 `assets/` 상대경로다.
- `slides/workflow-orchestrator.html`은 외부 로드가 없다. PNG 저장은 브라우저 안에서 SVG를 캔버스로 그려 내려받는다.
- 두 HTML 모두 열어도 네트워크로 데이터를 보내거나 AI 작업·설치·배포를 실행하지 않는다. GitHub·YouTube·LinkedIn·강의 링크는 클릭할 때만 새 탭으로 열린다.
