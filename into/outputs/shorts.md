# 쇼츠

보는 사람이 궁금한 것: 나랑 무슨 상관인가 · 그래서 답이 뭔가 · 더 보려면 어디로

자료 포맷의 칸 가운데 **하나만 답으로 고르고** 나머지는 다른 편이나 롱폼으로 보낸다. 55초, 세로 9:16.

| 칸 | 시간 | 화면 | 말 |
|---|---|---|---|
| 훅 | 0:00–0:04 | 답할 것이 이미 있다(숫자·전후·질문). 구석에 버전이나 날짜 | 짐작과 다른 문장 하나. 조건을 떼지 않는다 |
| 한 줄 요약 | 0:04–0:10 | 이름과 하는 일 | 무엇인지만 |
| 부품 | 0:10–0:18 | 그림 하나, 상자 셋까지 | 예에 나올 이름만. 예로 충분하면 시간을 예에 준다 |
| 예 하나 | 0:18–0:40 | **같은 그림**이 단계마다 한 번 바뀐다(3~4단계) | 따라가기 칸을 끝까지 |
| 답과 조건 | 0:40–0:50 | 첫 화면에서 달라진 곳만 | 훅의 답, 안 맞는 때 하나 |
| 다음 | 0:50–0:55 | 관련 영상 자리. 없으면 답에서 끝낸다 | 어디서 무엇을 더 보나 |

| 자료 | 훅과 답 | 예 하나 | 버리는 칸 |
|---|---|---|---|
| PR | 왜 바꿨나 | 전 → 후 | 순서·파일·대안. `바뀌지 않은 것`은 조건으로 |
| 저장소 | 기억할 것 1번 | 요청 하나 | 구조 표, 기억할 것 2·3, 설치 |
| 논문 | 핵심 결과 하나 | 방법(참가자 하나) | 배경. `한계`는 **버리지 않고** 조건으로 |
| 개념 | 왜 있나, 예가 아닌 것 | 예시 | 쓰임·정의 |
| 커리큘럼 | 졸업 과제 | 첫 주 하나 | 대상·지표 |
| 그 밖 | 짐작과 다른 칸 | 따라가기 칸 | `자세히`의 칸 |

- 말: 초당 5음절로 세고 칸마다 5.5를 넘기지 않는다. 넘으면 조건이 아니라 다른 사실을 뺀다. 고정 문구의 시간을 먼저 뺀다. 목소리가 없으면 읽을 시간(0.5초 + 낱말당 0.3초)을 준다.
- 실수: 칸을 다 넣어 목록이 된다. 훅과 답이 다른 것을 말한다. 긴 영상을 앞말 없이 잘라 시작한다.
- 넘길 때: 이 표를 쇼츠 그리는 스킬에 준다. 글꼴·목소리·자막은 그 스킬 일이다.
