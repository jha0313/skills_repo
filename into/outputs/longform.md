# 롱폼

보는 사람이 궁금한 것: 볼 만한가 · 결과가 언제 나오나 · 나는 무엇을 하면 되나

자료 포맷의 칸 순서를 쓰고 앞에 **도입**, 가운데 **뒤집기**, 뒤에 **다음**을 더한다. 10분, 가로 16:9. 8~15분이면 `예 하나`와 `다른 조건`만 늘이고 줄인다.

| 칸 | 시간 | 화면 | 말 |
|---|---|---|---|
| 하이라이트 | 0:00–0:15 | 이 영상에 실제로 나오는 결과만 | 제목의 답 한 문장 |
| 문제 | 0:15–0:25 | 겪는 장면 하나 | 누가 무엇을 하다 막히나 |
| 풀이 셋 | 0:25–0:35 | 낱말 셋 | 한 마디씩 |
| 가져갈 것 | 0:35–0:45 | 손에 남는 것 하나 | 무엇이고 어디 있나. 바로 시작 |
| 한 줄 요약 · 첫 결과 | 0:45–2:00 | 들어간 것과 나온 것을 나란히 | 처음과 끝. 가운데는 아직 |
| 전체 구조 | 2:00–3:00 | 그림 하나, 상자 다섯까지. 끝까지 쓴다 | 뒤에 나올 이름만 |
| 뒤집기 | 3:00–3:15 | 방금 본 것이 안 맞는 장면 | 주의할 점이나 한계를 질문으로 |
| 예 하나 | 3:15–6:15 | 같은 그림에서 지금 단계만. 실제 화면 | 따라가기 5단계, 30~40초씩. 첫 문장은 왜 |
| 다른 조건 | 6:15–7:45 | 표 한 장, 두 줄만 실제로 | `자세히`의 상황별·비교 칸 |
| 기억할 것 | 7:45–9:15 | 셋을 하나씩 | 오해하기 쉬운 것부터. 비용과 안 되는 것 |
| 누가 쓰나 | 9:15–9:45 | 쓴다 / 안 쓴다 | 오늘 할 일 하나 |
| 다음 | 9:45–10:00 | 종료 화면 | 다음 영상 하나 |

- 첫 결과 / 예 하나 / 다른 조건: PR 전·후 / 동작 순서 / 상황별 차이 · 저장소 요청과 돌아온 것 / 요청 하나 / 상황별 동작 · 논문 핵심 결과 / 방법(참가자 하나) / 비교 조건 · 개념 있을 때와 없을 때 / 예시 / 두 번째 예 · 커리큘럼 완성본 / 첫 주 / 섹션 하나
- 말: 초당 5음절. 화면만 보여 주는 시간을 따로 적고 고정 인사와 마무리의 시간을 먼저 뺀다.
- 그림: 전체 구조 그림을 계속 바꾼다. 읽은 기준(버전·날짜)을 구석에. 코드 지도·파일별 변경 같은 표는 설명란으로.
- 실수: 배경으로 시작한다. 칸 이름을 차례로 읽는다. **돌려 보지 않은 것을 돌려 본 것처럼 보여 준다.** 끝났다고 하고 더 말한다.
- 넘길 때: 표를 슬라이드나 영상 편집 스킬에 준다. 챕터는 칸 시작 시각.
