# shorts — 60초 세로 영상 (9:16)

`shorts.json`을 쓰고 `render`하면 스크립트가 장면마다 음절을 읽는 소리로 세고 시간을 정해 대본·스토리보드(`into-out/<slug>-shorts.md`)를 만든다. 60초를 넘거나 초당 5.5음절을 넘으면 FAIL이다.

```json
{"scenes":[
 {"slot":"hook","say":"나레이션","title":"화면 위 한 줄","caption":"자막 핵심어","visual":"그림(간선은 발신 → 수신: 라벨)","f":["f3"]},
 {"slot":"one",…},{"slot":"why",…},{"slot":"pic",…},{"slot":"run",…},{"slot":"catch",…}],
 "answer":"훅이 질문이면 답하는 장면 번호","check":"확인 질문 → 답"}
```

유형마다 어떤 장면을 쓸지는 `formats/<유형>.md`의 `## shorts` 표.

## 쓰는 법

1. **훅은 사실 하나.** 원문에서 가장 뜻밖인 문장의 한정어를 그대로 살린다. 질문 훅이면 영상 안에서 답한다. 0초 화면에 훅과 그 조건이 이미 보인다.
2. **장면 하나 = 생각 하나 = 움직임 하나.** 글자를 읽게 하지 말고 그림이 바뀌게 한다(간선이 켜진다, 막대가 자란다, 전이 후로 바뀐다).
3. **나레이션은 말이다.** 짧은 문장, 식별자 대신 쉬운 이름. 조건을 지워 시간을 맞추지 않는다 — 다른 사실을 뺀다.
4. 자막은 나레이션보다 짧게. 화면 밖("대본 참고")을 가리키지 않는다. `추정`이면 말로도 추정이라고 한다.
5. 세로 그림은 노드 4~5개, 왕복은 선 하나에 `↓ 보내는 것`·`↑ 돌아오는 것`.
6. 호스트 규칙(CLAUDE.md 등)에 쇼츠 고정 문구가 있으면 넣고 그 시간을 먼저 뺀다.

## 렌더

HTML을 MP4로 만드는 도구(예: `hyperframes`)가 있으면 그 도구의 안내를 먼저 읽고 스토리보드를 넘긴다. 없으면 대본에서 멈추고 알린다(새로 설치하지 않는다).

- 안전 영역(1080×1920): 글자는 x 120–888, y 288–1248. y 840 아래는 x 780까지.
- 한글 폰트 파일을 프로젝트에 두고 `@font-face`로 넣는다. 프레임을 뽑아 확인한다.
- 목소리·음악은 사용자가 말한 대로. 목소리가 없으면 나레이션의 조건까지 화면 글자가 싣고, 글자 묶음은 `0.5초 + 단어당 0.3초` 이상 보인다.
- `ffprobe`로 길이를 보고 0초·중간·끝 프레임을 눈으로 본다.
