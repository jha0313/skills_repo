# 사실 카드 — 짧은 자리에서 조건을 잃지 않게

평가에서 가장 많이 나온 오류는 틀린 사실이 아니었다. 본문은 맞는데 제목·훅·라벨·자막·보기 같은 **짧은 자리에서 조건이 빠지는 것**이었다. 같은 사실이 결과 안 여러 자리에 나오는데 조건은 한 자리에만 붙는다. 규칙을 아는 것만으로는 막지 못했다. 그래서 쓰기 전에 카드를 만들고, 쓴 뒤에 검색으로 대조한다.

## 1. 쓰기 전: 사실 카드 만들기

첫 into에서 칸에 쓸 사실(숫자·주장·식별자·판정)마다 한 줄을 만든다. 출력에 넣지 않는 작업 메모다(사용자가 원하면 보인다).

| 사실 | 조건·범위·예외 | 한정어 | 주체 | 종류 | 근거 |
|---|---|---|---|---|---|
| 재시도 창이 지난 뒤에도 끝날 수 있다 | 재시도 창이 지난 뒤 | can | 원문: 작업 | — | raw:38 |
| 요청을 캐시에서 돌려준다 | 기본(설정 `cache=off`이면 아님) | — | 원문: 프록시 | 동작 | raw:20 |
| `v2 full sweep` | — | — | — | 원문 표기(종류를 말하지 않음) | raw:11 |

(표의 내용은 형식 예시일 뿐 특정 원문의 사실이 아니다.)

- **조건·범위·예외:** only·if·default·최악의 경우, 표본·데이터셋·과제·표·그림, 제품·버전·설정, "~를 제외하고".
  - **기본값:** 설정·프리셋·모드에 따라 달라지는 동작은 숫자·식별자가 없는 문장이어도 카드에 넣는다. 조건 열에 `기본` 또는 그 설정을 적고, 원문이 그 동작을 끄는 설정을 들면 함께 적는다.
  - **진입 조건:** 코드 경로의 사실이면 그 줄에 닿기 위한 바깥 조건(가드, `&&`, 앞선 분기, 앞선 오류 종류)을 적는다.
  - 기본값과 진입 조건은 `빠진 디테일`로 보내지 않는다. 짧은 자리에서도 같은 줄에 남긴다.
- **한정어:** 원문에서 먼저 뽑는다: can·may·might·probably·possibly·likely·at least·about·often, ~경향·~수 있다·~경우·최소. 시간·규범 한정어도 뽑는다: immediate·initially·as a starting point·unless·for now, RFC 2119의 MUST(반드시)·SHOULD(권고)·MAY(해도 된다).
- **주체:** 그 동작을 하는 쪽. `원문`(원문이 행위자로 적음) · `추정`(원문 두 문장을 이어 정함) · `없음`. 그림 간선의 출발 노드와 문장의 주어는 이 열과 같아야 한다. `추정`이면 간선과 문장에 `(추정)`을 단다.
- **종류:** 식별자가 무엇인지(경로·브랜치·커밋·버전 라벨·파일·설정 키·패키지 이름). 원문이 종류를 말하지 않으면 원문 표기 그대로 쓰고 종류를 붙이지 않는다. 관계를 말하는 사실이면 관계의 종류도 적는다: 소속·위치·가리킴(참조)·소비.
- **숫자:** 무엇의 숫자인지까지 적는다(전체·부분, 전·후, "비용 대비 가치가 있는 경우의 5%").
- **원문 내부 불일치:** 원문 두 곳이 같은 대상을 다르게 말하면(범위·부등호·표 번호) 한 줄로 넣는다: 양쪽 위치, 차이, 표시 `(불확실)`. 그 대상을 쓰는 모든 모드에서 2절로 대조한다.
- 다음 모드는 카드를 새로 만들지 않는다. 카드의 줄을 원문과 한 번 더 대조해 고친 뒤 쓴다(SKILL.md 5절).

## 2. 쓴 뒤: 핵심어로 검색해 모든 자리 대조

조건·한정어 열이 비어 있지 않은 사실마다:

1. 그 사실의 핵심어로 결과 전체를 검색한다: 식별자·숫자·주어 명사. 숫자·식별자가 없는 동작 문장이면 동작의 대상 명사와 동사(예: "샌드박스"·"실행")로 찾는다.
2. 나오는 **모든 자리**를 본다: 제목(h1·표지·슬라이드 제목·챕터 제목), 굵은 머리말, TL;DR 첫 줄, 훅, 비유 줄, `비유가 깨지는 곳`, 카드 제목, SVG 라벨, `aria-label`, 시퀀스 메시지, `Note`, 식별자 표의 설명 열, `전:` 캡션, 자막, 화면 텍스트, 스토리보드의 요지·화면 텍스트 열, 나레이션, 보기, 해설, 발표자 노트, 확인 질문의 답, `한 칸 위로`. TL;DR 첫 줄·정리 장 제목·마무리 나레이션은 반드시 본다. 같은 사실을 가장 짧게 다시 쓰는 자리다. 제목에 조건을 달았어도 그 아래 단계 문장·글로 읽기·스토리보드 행은 따로 본다.
3. 자리마다 조건이 같은 줄에 있는지 본다. 자리가 좁으면 `(조건부)`·`(예외 있음)`·`(일부)` 꼬리표를 붙이거나 문장을 약하게 쓴다. 조건을 지우고 자리를 맞추지 않는다.
4. 본문에서 `(추정)`·`(불확실)`인 사실은 그림 간선·`aria-label`·제목·화면 문구에서도 같은 표시를 단다. 그림에서는 라벨에 `(추정)`을 달거나 점선으로 그린다.
5. **거꾸로도 본다:** 결과에 쓴 `만`·`뿐`·`항상`·`모두`·`반드시`를 검색해, 원문에 같은 한정이 있는지 본다. 없으면 지운다.

## 3. 금지 변형 (줄이다가 뜻이 바뀌는 예)

| 원문 | ✗ 바뀐 것 | 잃은 것 |
|---|---|---|
| 할 수 있다 · can finish after | 한다 · 끝까지 간다 | 가능 → 단정 |
| 않아도 된다 | 하지 마라 | 허용 → 금지 |
| default false | 꺼져 있었다 · 기능이 없다 | 기본값 → 상태 |
| still makes mistakes | 줄지 않는다 | 비교 → 부정 |
| not clear how to measure · 측정 방법을 밝히지 않는다 | 측정할 수 없다 · 측정값이 아니다 | 미제시 → 부정 |
| over 1000 · at least five | 1000 · 다섯 가지 | 하한 → 정확값 |
| probably the most | 1순위 | 추정 → 순위 |
| X 덕분에 가능하다 | X가 없으면 불가능하다 | 이유 → 반사실 |
| 포맷을 깨뜨리는 편집보다 낫다 | 직접 편집보다 낫다 | 비교 대상 |
| 조건이 맞으면 실행한다 | 이벤트마다 실행한다 | 조건 |
| 110~160 구간에서 1/3 | 120을 지날 때마다 1/3 | 구간 → 한 점 |
| `v2 full sweep`(점검 이름) | v2 브랜치 | 식별자 종류 |
| No new tests needed | 새 테스트를 더하지 않았다 | 판단 → 행동 |
| runs in X by default | X에서 돈다 | 기본값 → 항상 |
| When X, Y | X일 때만 Y | 원문에 없는 한정 추가 |
| won't automatically allow | 통과하지 않는다 · 막는다 | 자동 허용 아님 → 차단 |
| 힌트가 zone A를 가리키는 endpoint | zone A에 있는 endpoint | 가리킴 → 위치 |
| No immediate plans · 바로 ~하지 말고 | 계획 없음 · ~하지 말고 | 시간 한정어 |
| SHOULD | 한다 · 해야 한다 | 권고 → 의무 |

## 4. "없다"도 사실 주장이다

`원문에 없음`, `원문은 ~라고만 말한다`, `(불확실)`, "X 없음", "반대 의견 없음", "작성자 답글 없음"은 모두 사실 주장이다. 쓰기 전에:

- 원문 **전체**를 핵심어로 검색한다. 식별자, 주체·동사(summary·produces·generates·poll 같은 말), 동의어를 함께 찾는다. 잘린 목록이나 일부 범위로 판정하지 않는다.
- "X 없음"이면 같은 목록에서 이름이 비슷한 항목(다른 버전·다른 경로)을 함께 적는다. 그 항목이 원래 주장을 검증하는지 모르면 `(확인 안 함)`.
- 읽은 범위가 일부면 범위를 붙인다: "읽은 범위에서 직접 반박한 댓글 없음".
- 작성자 이름을 지운 사본이면 작성자 답글 여부는 `확인 불가`.
- 근거 줄 번호는 그 줄에 그 식별자·문장이 실제로 있는지 다시 본다(셸이 있으면 `grep -n`). 줄 수는 `wc -l` 값을 쓴다. 칸 끝에 근거를 묶어 달았으면 칸 안의 숫자·식별자마다 지원 줄이 그 묶음 안에 있는지 본다.
- "없다·같다·모두"가 든 요약 문장(Insights·정리 장)은 그 요약이 묶은 행·항목을 하나씩 다시 대조한다. 부재는 셋으로 나눠 쓴다: 표현 자체 없음 / 같은 대상의 근거 없음 / 측정 방법 없음. 확인한 자료와 주장한 자료를 바꾸지 않는다(대본에서 찾지 못함 ≠ 영상에 없음).

## 5. 한 단계 추론도 `(추정)`

- 원문 두 문장을 이어 새 판단을 만들면 `(추정)`. 예: "두 숫자의 출처가 다르다" → "같은 조건의 비교가 아니다".
- 원문 밖 통상 정의로 원문을 평가하면 `(보충: 출처)`를 단다. 기억만으로 평가하지 않는다.
- 원문이 원인을 말하지 않으면 인과 설명·비유가 깨지는 곳에서도 원인을 붙이지 않는다.
