# paper-concept — 논문·개념
- 질문: 무엇이 어떻게 달라졌나(개념이면 무엇인가) · 왜 그런가 · 어디까지 믿어도 되나
- 그림: claim

## model
- 참고: 결과 숫자가 있으면 `results`가 주 그림(막대), 없으면 간선이 주 그림(흐름). 한 판의 숫자를 다른 판 기준선과 섞지 않는다. 저자의 suggest·may를 단정으로 바꾸지 않는다.

| 키 | 형 | 개수 | 쓸 것 |
|---|---|---|---|
| results | list{id,group?,label,value,unit?,base?,cond?,src} | 0–12 | group=비교한 조건, label=지표, base=기준, cond=자료·유의성(`차이 없음`) |
| claims | list{id,t,results?,src} | 0–4 | 저자 주장과 받치는 결과 id |
| limits | list{id?,t,src} | 1–4 | 저자가 적은 한계. 내가 본 것은 `(추정)` |
| flips | list{id,if,then,edges?,src} | 0–8 | 개념: 조건이 바뀌면 달라지는 것 |

## 예
**논문·개념 · AI 과외와 수학 학습(PNAS 2025)** — 안전장치 없는 GPT-4로 연습한 반은 AI를 치운 시험에서 AI 없는 반보다 17% 낮았다(튀르키예 고교 한 곳)

**왜** · AI가 일을 빠르게 한다는 연구는 많지만 배움에 어떤지는 몰랐다 · AI는 틀릴 수 있어, 배우지 못하면 검토할 실력이 없을 수 있다

**결과**

| 조건 | 연습(AI 있음) | 시험(AI 없음) |
|---|---|---|
| 책·노트만 (기준) | 0.28 | 0.32 |
| GPT Base | +48% | **−17%** |
| GPT Tutor | +127% | 차이 없음 |

**비교한 것** · GPT Base — 챗 그대로 · GPT Tutor — 답 대신 힌트, 교사가 정답·흔한 실수를 넣어 둠
**어떻게 쟀나** 약 50개 반(1,000명 가까이)을 반 단위로 무작위 배정 → 90분 수업 4번: 같은 복습 → 도구만 다른 연습 → 비슷한 짝 문제를 혼자 시험

**왜 그랬나**
- 저자 해석은 베끼기다
- Base 반은 주로 "답이 뭐야?"를 묻고, Tutor 반은 도움을 청하거나 먼저 풀었다
- Base는 정답이 51%뿐이지만, 논리 오류가 짝 시험을 낮췄다는 증거는 없었다

**여기까지만** · Tutor도 시험을 올리지는 못했다 · Base 반은 덜 배웠다고 느끼지 않았다 · 한 학교, 수학, 2023년 가을, 단기 결과다
