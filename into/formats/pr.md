## 예
**PR · stdio 도구 서버(MCP) 늦게 켜기가 기본** — 도구 목록이 이미 캐시돼 있으면, Codex가 선택(optional) stdio MCP 서버를 첫 도구 호출 때까지 안 켤 수 있다.

```
상황    도구 목록이 캐시된 채로 Codex를 켠다
전      Codex 시작 ─(바로 켠다)▶ 선택 서버
후      Codex 시작 ─(캐시된 도구를 보여 준다)▶ 세션 ─(첫 도구 호출)▶ 선택 서버
그대로  필수(required) 서버는 시작할 때 바로 연결한다
```

**어떻게** 기능 스위치 `mcp_lazy_stdio_startup`: 개발 중·기본 꺼짐 → 정식(`Stable`)·기본 켜짐
**조심** · 바꾼 이유, 캐시가 없을 때, 첫 호출에서 켜기가 실패할 때는 원문에 없다 · 예전 방식 시험은 스위치를 끈 설정으로 한다
**규모** 파일 4개, +13 −10
