# 영상

읽는 사람이 궁금한 것: 나한테 볼 만한가 · 답은 몇 분에 있나 · 무엇을 따라 하나

| 단계 | 칸 | 채울 것 |
|---|---|---|
| 간단히 | 한 줄 요약 | 누구에게 무엇을 보여 주나 + 길이 |
| | 볼 사람 | 이런 사람은 다, 이런 사람은 ○분~○분만 |
| | 타임라인 | 그림: 시각 · 질문 → 답. 5~7줄 |
| | 핵심 셋 | 영상이 실제로 한 말 |
| | 따라 하기 | 절차 하나를 끝까지 |
| 자세히 | 타임라인 넓히기 | 줄마다 설명·시연·의견 표시 |
| | 조건 | 결과가 달라지는 때 |
| | 다시 볼 곳 | 시각과 이유 |
| 아주 자세히 | 주장과 근거 | 주장 · 시각 · 보여 줬나 말만 했나 |
| | 빠진 것 | 영상이 답하지 않은 질문 |
| | 확인 질문 | 질문 셋과 답이 있는 시각 |

- 그림: 막대 폭은 실제 길이에 맞춘다.
- 실수: 제목·썸네일만 보고 쓰지 않는다. 자막이나 본문이 없으면 달라고 한다.
- 참고한 구조: 시각을 붙인 질문·답 요약(따로 확인한 출처 없음)
