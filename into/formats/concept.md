# 개념

읽는 사람이 궁금한 것: 그게 뭔가 · 왜 있나 · 어디까지가 그것인가

| 단계 | 칸 | 채울 것 |
|---|---|---|
| 간단히 | 한 줄 요약 | 무엇인가. 하는 일(또는 일어나는 일)로. ELI5면 비유 하나와 안 맞는 데 한 줄 |
| | 왜 있나 | 이것이 없거나 모르면 생기는 일 하나 |
| | 전체 구조 | 그림: 누가 누구에게 무엇을 |
| | 예시 | 하나를 끝까지, 5단계 안에서 |
| | 예가 아닌 것 | 비슷하지만 아닌 것 하나와 다른 점 |
| | 쓰임 | 언제 쓰나, 또는 어떻게 피하나 하나 |
| 자세히 | 두 번째 예 | 조건이 다른 예. 무엇이 같고 다른지 |
| | 흔한 오해 | 오해 → 실제 |
| | 정확한 정의 | 원문의 정의. 출처와 함께 |
| 아주 자세히 | 내부 동작 | 실제 이름으로 |
| | 쓰지 않을 때 | 한계와 다른 방법 |
| | 더 읽을 것 | 공식 문서, 만든 사람의 글 |

- 그림: 비유가 아니라 실제 동작을 그린다.
- 실수: 사전식 정의로 시작하지 않는다. 정확한 정의는 `자세히`에.
- 참고한 구조: [풀이된 예 효과](https://en.wikipedia.org/wiki/Worked-example_effect) — 처음 배우는 사람은 풀어 놓은 예를 볼 때 부담이 줄고, 잘 아는 사람에게는 효과가 줄어든다
