## model
- 참고: 범위 둘. `지도(전체)`는 zones가 폴더가 아니라 책임 5–9개, path는 요청 하나의 한 바퀴. `구역(<이름>)`은 zones가 그 안의 책임 3–6개. 구역 이름에 든 낱말마다 사실이 하나는 있어야 한다.

| 키 | 형 | 개수 | 쓸 것 |
|---|---|---|---|
| zones | list{id,t,does,grade:"읽음\|훑음\|목록만",src} | 3–9 | 책임 한 줄. `목록만`이면 이름과 수만 |
| path | list | 3–8 | 요청 하나가 지나는 간선 id. 호출 위치를 읽은 것만 |
| flips | list{id,if,then,edges?,src} | 0–12 | 상황 → 결과. 기본값·미지원·실패·한도·순서. 설정 이름과 기본 켜짐/꺼짐까지 |

## 예
**저장소 · Codex 구역(컨텍스트 구성·압축·지시문)** — 지시문·환경·대화 기록을 모아 모델에게 보낼 글(컨텍스트)을 만들고, 창이 차기 전에 옛 기록을 압축한 새 기록으로 바꿔 대화를 잇는다.

**왜** 보통 요청이 모델의 창을 넘으면 재시도 없이 그 턴이 오류로 끝난다(심사용 Guardian 세션 예외).

```
지시문·환경 ─(처음엔 전부, 뒤에는 바뀐 조각만)▶ 대화 기록 ─(정리한 사본)▶ 모델
모델 ─(답 · 사용량)▶ 대화 기록 ─(한도 도달 = 보통 창의 90%)▶ 압축기
압축기 ─(기록 사본)▶ 모델
모델 ─(요약)▶ 압축기 ─(새 기록)▶ 대화 기록
```

**나오는 것** 보통 순서: 도구 선언·기본 지시문 → 남긴 사용자 메시지 → 새 AGENTS.md·환경 → 마지막 사용자 메시지 → 요약. 옛 답·도구 결과는 빠진다(보존 항목 예외). 최근 것부터 원격 64,000 · 로컬 20,000토큰(추정)

**이러면 → 이렇게**

| 상황 | 결과 |
|---|---|
| 턴 중간에 한도 도달 | 이어서 할 일이 있을 때만 압축. 없으면 다음 턴 시작 전에 다시 잰다 |
| 원격 압축 지원 / 미지원 | 압축 항목 1개를 받는다(아니면 실패) / 요약 글을 부탁한다(로컬) |
| 압축 요청도 창을 넘음 | 원격은 실패 / 로컬은 가장 오래된 것부터 빼고 다시 |
| `token_budget` 켬(기본 꺼짐) | 요약 없이 새 창 |
| AGENTS.md가 여럿 | 루트(기본 `.git`) → 현재 폴더 순서. 폴더마다 하나(AGENTS.override.md 먼저) |
