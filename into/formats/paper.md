# 논문

읽는 사람이 궁금한 것: 그래서 무엇을 알아냈나 · 어떻게 알아냈나 · 어디까지 믿어도 되나

| 단계 | 칸 | 채울 것 |
|---|---|---|
| 간단히 | 한 줄 요약 | 알아낸 것 하나를 말로. 숫자는 핵심 결과에서 |
| | 배경 | 그전에는 무엇을 몰랐나 |
| | 핵심 결과 | 막대나 숫자 하나. 누구에게 쟀고 기준이 무엇인지 |
| | 방법 | 참가자(또는 데이터) 하나가 겪는 일을 순서대로 |
| | 한계 | 이 결과가 말하지 않는 것 1~2개 |
| 자세히 | 비교 조건 | 표: 바꾼 것 하나 · 조건 · 결과가 남았나 |
| | 저자의 해석 | 결과와 해석을 나눈다. 다른 설명이 남았나 |
| | 결과가 달라지는 조건 | 결과가 작아지거나 뒤집힌 곳만. 위 표에 없는 것 |
| | 활용 | 재 본 것과 저자의 제안을 나눈다 |
| | 최신성 | 나온 때, 다른 연구자가 심사했나 |
| 아주 자세히 | 다섯 가지 평가 | 종류 · 이어지는 연구 · 가정이 맞나 · 새로 보탠 것 · 글이 분명한가 |
| | 재현 | 같은 결과를 내려면 필요한 것, 숨은 가정 |
| | 약점 | 표본, 측정, 통계 |
| | 다음 읽을 것 | 이 논문이 기댄 글과 반대되는 글 |

- 그림: 결과 하나만 크게. 기준선을 그리고, 차이가 없으면 없다고 쓴다.
- 실수: 초록의 자랑을 옮기지 않는다. 숫자는 표에서 가져와 무엇의 숫자인지 적는다.
- 참고한 구조: [Keshav, How to Read a Paper](https://www.cs.princeton.edu/courses/archive/fall10/cos597B/papers/howtoread-keshav.pdf)(세 번 읽기 = 세 단계), [Cochrane 쉬운 요약](https://training.cochrane.org/guidance-writing-cochrane-plain-language-summary)(핵심 먼저, 한계를 쉬운 말로 — 검색 요약으로만 확인)
