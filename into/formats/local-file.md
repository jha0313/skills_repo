# 파일 하나 (코드 · 설정 · 프롬프트)

읽는 사람이 궁금한 것: 무엇을 넣으면 무엇이 나오나 · 언제 쓰나 · 어디를 고치면 되나

| 단계 | 칸 | 채울 것 |
|---|---|---|
| 간단히 | 한 줄 요약 | 무엇을 받아 무엇을 내놓나 |
| | 쓰임 | 누가, 무엇을 하다가 |
| | 입력과 출력 | 그림: 입력 → 하는 일 → 결과 |
| | 입력 하나 따라가기 | 입력 하나를 끝까지 |
| | 주의할 점 | 오류 없이 틀리는 것 하나 |
| 자세히 | 규칙 | 표: 이럴 때 · 이렇게 |
| | 값과 기본값 | 바꾸면 달라지는 값 |
| | 고칠 곳 | 바라는 것 · 고칠 줄 · 함께 바뀌는 것 |
| | 파일 지도 | 줄 범위 · 하는 일 |
| 아주 자세히 | 어긋나는 규칙 | 줄 번호와 함께 |
| | 의존하는 것 | 밖에서 가져오는 파일·요청 |

- 그림: 결과가 여럿이면 결과마다 한 줄.
- 실수: 위에서 아래로 한 줄씩 읽어 주지 않는다.
- 참고한 구조: 입력 하나를 손으로 따라가며 읽기(따로 확인한 출처 없음)
