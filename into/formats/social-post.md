# X·스레드 글

읽는 사람이 궁금한 것: 누가 무슨 말을 했나 · 근거가 있나 · 나도 그대로 믿어도 되나

| 단계 | 칸 | 채울 것 |
|---|---|---|
| 간단히 | 한 줄 요약 | 누가 무엇이라고 했나 |
| | 이유 | 글쓴이가 든 이유 |
| | 주장과 근거 | 그림: 주장 3~5줄. 앞에 `잰 값`·`인용`·`경험`·`말뿐` |
| | 핵심 주장 따라가기 | 가장 중요한 주장 하나를 순서대로 |
| | 검증할 것 | 확인할 것 하나 |
| 자세히 | 글 순서 | 전체 중 몇 번째인지와 한 줄씩 |
| | 조건 | 글쓴이가 건 단서, 다른 조건이면 |
| | 반대 의견 | 글 안이나 답글에서. 없으면 없다고 |
| 아주 자세히 | 출처 추적 | 멈추기 → 누구인가 → 다른 믿을 만한 곳은 → 원래 맥락은 |
| | 인용 범위 | 내가 옮겨도 되는 범위 |

- 그림: 주장마다 한 줄, 근거 종류는 색이 아니라 낱말로도.
- 실수: 좋아요 수는 근거가 아니다. 찾아보지 않은 것을 `틀렸다`고 쓰지 않는다.
