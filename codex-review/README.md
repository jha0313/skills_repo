# codex-review

코드·계획·문서 리뷰를 **다른 회사 모델(Codex CLI)** 에게 맡기는 스킬입니다. `codex exec` 호출 모양을 하나로 고정하고, 돌아온 지적을 **확인한 뒤에만** 반영하게 합니다.

## 언제

- 한 모델이 만든 변경을 다른 모델의 눈으로 보고 싶을 때
- `codex exec`를 손으로 짜다가 옵션이 매번 달라지거나 백그라운드에서 멈출 때

## 설치

```bash
npx skills add jha0313/skills_repo --skill codex-review
```

필요한 것: macOS 또는 Linux, Python 3.11+, 로그인된 [Codex CLI](https://github.com/openai/codex). Windows는 지원하지 않습니다.

## 예시

> **나:** 이 브랜치 Codex한테 리뷰 맡겨 줘.
>
> **에이전트:** `acme-web`에 비밀 파일이 없는 것을 확인했습니다. 나가는 것: 프롬프트 1.2KB와 Codex가 읽는 파일. (실행)
>
> 지적 4개 중 2개 확인, 1개 틀림, 1개 확인 못 함.
>
> | # | 심각도 | 지적 | 판정 | 근거 | 조치 |
> |---|---|---|---|---|---|
> | 1 | 높음 | 만료된 토큰을 받아들임 | 확인됨 | 테스트로 재현, `auth.py:41` | 고침 |
> | 2 | 중간 | 목록 쿼리 N+1 | 확인됨 | 쿼리 로그 51건 | 고침 |
> | 3 | 중간 | `None` 처리 누락 | 틀림 | `auth.py:12`에서 이미 막음 | 안 함: 일어나지 않음 |
> | 4 | 낮음 | 동시 로그인 경합 | 확인 못 함 | 재현 환경 없음 | 사용자가 정할 일 |
>
> 2라운드에서 새로 확인된 높은 심각도 지적이 없어 멈췄습니다.

## 설정 (환경 변수, 모두 선택)

| 이름 | 기본 | 하는 일 |
|---|---|---|
| `CODEX_BIN` | `codex` | 실행 파일 |
| `CODEX_REVIEW_MODEL` | 없음 | `--model` 기본값. 없으면 Codex 설정을 따름 |
| `CODEX_REVIEW_BLOCK` | 빈 목록 | 작업 폴더로 주지 않을 폴더(`~/a:~/b`). 그 안과, 그것을 품은 상위 폴더를 거절 |
| `CODEX_REVIEW_LOG` | 안 남김 | 실행 기록 파일. 시각·작업 폴더·종료 코드·초·크기·모델만. 프롬프트는 남기지 않음 |

스크립트 종료 코드: 0 성공 · 1 결과가 비었거나 ping 실패 · 2 잘못된 입력(프롬프트·결과·로그·`.prev`·실행 기록 경로가 겹칠 때 포함) · 124 제한 시간 · 127 codex 없음 · 그 밖은 codex의 코드.

## 못 하는 것과 위험

- **읽기를 막지 못합니다.** codex-cli 0.167.2(macOS)에서 `codex sandbox -c 'sandbox_mode="read-only"'`로 확인: 작업 폴더 밖 파일 읽기는 되고, 쓰기는 작업 폴더 안도 거절됩니다(2026-11-24). `CODEX_REVIEW_BLOCK`은 `--cd`, `--add-dir` 인자만 검사하므로 실수 방지용입니다. 정말 보이면 안 되는 자료는 다른 계정이나 컨테이너로 나누세요.
- **사용자의 Codex 설정을 그대로 씁니다.** MCP 서버, 훅, `AGENTS.md`도 함께 읽힙니다. Codex는 세션 기록을 `$CODEX_HOME`에 남깁니다.
- **로그에 내용이 남습니다.** `<결과>.log`에는 프롬프트와 Codex의 출력이 들어 있습니다. 결과·로그·`.prev`는 0600(나만 읽기)으로 만들지만, 직접 쓴 프롬프트 파일의 권한은 바꾸지 않습니다. git에 올리지 마세요.
- **웹 검색 값은 Codex 버전에 묶입니다.** 기본은 `web_search="disabled"`(검색 도구 없음), `--web`이면 `web_search="live"`를 늘 명시해서 사용자 설정의 검색 모드를 물려받지 않습니다([설정 문서](https://learn.chatgpt.com/docs/config-file/config-reference), 2026-11-24). 0.167.2에서 `live`를 주면 외부 웹 접근이 켜지는 것은 실행으로, `disabled`의 뜻은 문서로 확인했습니다. 다른 버전에서 값이 바뀌었으면 `scripts/codex_review.py`의 `WEB_KEY` 줄을 고치세요. MCP 도구나 셸 명령의 네트워크는 이 값이 막지 않습니다.
- 지적이 맞는지는 보장하지 않습니다. 그래서 확인 단계가 있습니다.
