# 시간대 변환

시각 계산은 머리로 하지 않고 `scripts/when.py`로 한다. 결과는 이 컴퓨터의 시간대 자료만큼 맞다. 자료가 오래됐거나 앞으로 규칙이 바뀌면 틀릴 수 있다. 입력은 한국어와 숫자 표기를 읽고 출력은 한국어다.

## 언제 쓰나

- 회의 시간 제안, 예약 발행, 마감처럼 시간대가 섞인 시각·요일·남은 시간을 답하거나 글에 적기 전.
- 쓰지 않는 때: 시간대가 하나뿐이고 계산이 없을 때, 반복 일정·영업일·공휴일 계산(하지 못한다).

## 순서

1. **시간대를 정한다.** 도시·나라를 IANA 이름으로 바꾼다(서울 → `Asia/Seoul`). 시간대가 여럿인 나라(미국·캐나다·호주 등)나 약자(EST, CST, IST)만 있으면 사용자에게 도시를 묻는다. 말이 없으면 이 컴퓨터(`여기`)다.
   완료: `--from`과 `--to`가 모두 IANA 이름, `여기`, `UTC`, 또는 사용자가 설정한 별칭이다. **정하지 못했으면 2로 가지 않는다.**
2. **돌린다.**
   ```bash
   python3 -I scripts/when.py "2025-11-24 14:00" --from Asia/Seoul --to 여기,Europe/London
   python3 -I scripts/when.py "금 오후 1시" --from Asia/Seoul      # 오늘 이후 첫 금요일
   python3 -I scripts/when.py now --to Asia/Seoul,UTC --json
   ```
   읽는 입력: `2025-11-24 14:00`, `11/24(월) 오후 2시`, `11월 24일 14시 반`, `금 13:00`, `내일 9시`, `now`. 그 밖의 말("다음 주 금요일", "어제")은 날짜로 풀어 쓴다. 오늘 날짜와 요일은 `now`로 확인한다.
   완료: 종료 코드를 확인했다.
3. **종료 코드대로 한다.**

   | 코드 | 뜻 | 할 일 |
   |---|---|---|
   | 0 | 정상 | `가정:` 줄이 있으면 같이 전한다 |
   | 2 | 못 읽음 | 오류가 말한 부분을 고쳐 다시 돌린다. 머리로 계산해 넘기지 않는다 |
   | 3 | 경고 | 경고를 그대로 전하고 사용자가 고르게 한다 |

   경고는 셋이다: 적은 요일이 날짜와 다름, 시계가 뒤로 가서 **두 번 오는 시각**(둘 다 보여 줌), 시계가 앞으로 가서 **없는 시각**(변환하지 않음).
   완료: 코드 0이거나, 경고를 사용자에게 보였다.

## 근거

- 답의 시각·요일·남은 시간은 출력에서 옮긴다. 다시 계산하거나 합치지 않는다. "1일"은 24시간이다.
- 스킬을 고쳤으면 `python3 tests/run_tests.py` 통과 결과를 보인다.

## 하지 말 것

- 두 도시의 시차를 외운 값으로 쓰기. 서머타임을 바꾸는 주가 나라마다 달라 같은 달에도 바뀐다.
- 사용자의 도시나 이동 일정을 짐작하거나 이 파일에 적기. 자주 쓰는 도시는 사용자가 환경 변수로 둔다: `WHEN_PLACES="서울=Asia/Seoul,런던=Europe/London"`. `--to`를 빼면 `여기`와 이 별칭들이 나온다.
- 경고가 난 시각으로 일정을 만들거나 메시지를 보내기.

## 답 형식

도시마다 한 줄: `도시: 날짜(요일) 시각 (UTC 시차, 전날·다음 날·이날 시차가 바뀜)`. 그다음 남은 시간(물었을 때), 가정, 경고.
